# 開発者モード 操作ガイド

動作確認用のデバッグ機能。エディタ（PIE）と Development ビルドでのみ使える。
**製品版（Shipping ビルド）には機能そのものが含まれない**（後述）。

## 使い方

1. PIE で戦闘シーンに入る（タイトル画面では使えない）
2. **F1** を押す → 画面右上に赤枠のパネルが出たら ON
3. 下表のキーで確認したい挙動を起こす
4. もう一度 **F1** で OFF（無敵・敵停止・スローは自動で元に戻る）

## キー一覧（開発者モード ON の間だけ有効）

### プレイヤー / 全体

| キー | 動作 | 主な確認対象 |
|---|---|---|
| **1** | プレイヤー即死 | `AM_Death` → `AM_Death_Idle` → ゲームオーバー（リザルト） |
| **2** | モンスター即死 | `AM_Monster_Death1` → ゲームクリア（リザルト） |
| **3** | プレイヤー無敵 ON / OFF | 敵の攻撃を受けずにじっくり確認 |
| **4** | モンスター停止 ON / OFF | 敵の AI・攻撃・移動を止める |
| **5** | HP 全回復 + ゲージ MAX | 大攻撃・コンボの確認 |
| **6** | プレイヤー被弾 | 被弾モーション（`AM_Damage`） |
| **7** | プレイヤースタン（2 秒） | スタンモーション（`AM_StunLoop`） |
| **8** | スロー（x0.25）ON / OFF | アニメのつながり・コンボキャンセルの確認 |
| **9** | リスタート | 現在のレベルを読み直す |

### モンスター（既存のデバッグキー）

| キー | 動作 |
|---|---|
| **U** | スタン |
| **I** | やられ |
| **O** | 死亡 |
| **N** | ガード成功の被弾をシミュレート |
| **M** | 通常被弾をシミュレート（スタン +15） |

※ これらも開発者モード ON の間だけ有効（以前は常時有効だった）。

## パネルの見方

- 1 行目: `[開発者モード]  F1: 閉じる`
- 中段: キー一覧
- 緑の行: 現在の状態（無敵 / 敵停止 / スロー）
- 黄色の行: 直前に実行した操作

## 確認手順の例

| 確認したいこと | 手順 |
|---|---|
| ポーズ画面の操作説明 | Esc →「操作説明」（開発者モード不要） |
| プレイヤー死亡の流れ | F1 → 1 |
| モンスター死亡の流れ | F1 → 2 |
| コンボのキャンセルタイミング | F1 → 3 → 4 → 5 → 8 → 攻撃を連打 |

## 注意

- リザルト画面に切り替わると開発者モードの入力は止まる（9 のリスタートも効かない）。
- 状態（ON / OFF）はエディタを閉じるまで保持される。

## 製品版で使えない仕組み

- 本体: `Source/CounterCore/Private/CounterCoreDevMode.cpp` は `#if !UE_BUILD_SHIPPING` で囲まれ、
  Shipping では `IsActive()` が常に false の空実装になる。
- 呼び出し側（`CounterCoreHUD.cpp` の `DrawHUD`、`MonsterCharacterBase.cpp` の `Tick` のデバッグキー処理）も
  `#if !UE_BUILD_SHIPPING` で除外。
- `PlayerCombatComponent::DevForceDeath()` も Shipping では何もしない。
- 確認済み: Shipping ビルドの exe に開発者モードの文字列が含まれていない。

開発者モードに機能を足すときは、必ず `#if !UE_BUILD_SHIPPING` の内側に書くこと。
